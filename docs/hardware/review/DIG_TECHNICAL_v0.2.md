## 프로그램과 동작 방식

D.I.G.는 Windows PC의 Python 중앙관제로 3WD 옴니휠 로봇을 운영하는 프로젝트다. 웹 미션 컨트롤은 초안 블록 편집, 예상 경로, 작업 이력, 문서 검색을 제공한다. 카메라 페이지에서는 손동작과 사람 추종 상태를 확인한다.

1. Agent가 자연어를 미션 편집, 상태 조회, 기술 문서 질문, 일반 대화로 분류한다. Nemotron은 의도와 답변을 별도로 처리한다. LangGraph가 흐름을 연결하고 Pydantic이 의도와 이동 제안의 형식을 확인한다.
2. 이동 명령은 SQLite 미실행 초안에 누적된다. 블록 추가·삭제·순서 변경은 미션 버전을 갱신한다. 웹의 2D 경로는 초안의 예상 경로다.
3. **Qt 관제**는 PySide6 데스크톱 운영 화면이다. 운영자가 장치와 안전 상태를 확인하고, 현재 미션 버전에 대해 실물 실행을 승인한다. Python은 RobotSession의 제어권, 레이더, 기존 STOP 조건을 확인하며 승인된 이동을 ESP32에 보낸다.
4. Raspberry Pi는 레이더 상태를 PC에 전달한다. PC는 `EVADE`와 `UNKNOWN`을 차단하고 긴급 정지를 별도로 처리한다. ESP32가 목표 도달을 보고한 뒤 새 STOP 응답을 확인해야 해당 단계가 완료된다. 미검증 회전은 미리보기로 다룬다.

## 서로 다른 하드웨어 자료

| 구성 | 출처와 검증 수준 |
| --- | --- |
| 브레드보드 시제품 | [BOM 이미지](../breadboard/bom_original.png)와 [9항목 CSV](../breadboard/BOM.csv). PCB BOM과 별도다. SZH-MDBL-00 두 개, PCA9685 TS0185 한 개, MG90S 네 개가 목록에 있다. 실제 장착과 핀배열은 확인 필요다. TERANTY 배터리 전압은 사용자 확인 기준 7.4V다. |
| PCB V18 | [V18 KiCad 감사](../pcb-v18/DESIGN.md)와 [제작 승인 기록](../pcb-v18/evidence/05_VALIDATION/MANUFACTURING_APPROVAL.json). HW166 형상 소켓은 CAD 정보다. `FAB_APPROVED=false`, `BLOCKED`, 견적 전용이다. 정적 검사와 A08 등 실물·보호 검증은 별개다. |

브레드보드 모듈을 PCB에 교체 장착할 수 있는지는 실물 핀배열, 치수, 소켓과 열·전원 적합성을 확인해야 한다. 현재 연결된 PCB 리비전은 보드 표기나 현장 기록으로 확인한다.

## 버전별 문서 검색

하드웨어 부품, 핀, 배선, 전원 질문에는 브레드보드·V18 중 범위를 먼저 선택한다. 두 리비전이 명시된 비교는 각 근거를 분리해서 표시한다. 인용에는 구성 ID, 리비전, 출처 경로, 검증 유형과 문서의 절 또는 쪽 정보를 기록한다.

시제품 BOM과 V18은 각각 명시적으로 허용한 발췌만 로컬 검색에 사용한다. 첨부 감사 ZIP과 CAD 원본은 자동 색인 대상에서 제외한다. 이 v0.2 기술 문서는 검토 컬렉션에 두며 일반 런타임 검색에서 제외한다. 실시간 상태는 관제 런타임을 조회한다.
